# Build & Verification Preferences

- **Build & Run**: Urusan build APK/bundle dan menjalankan aplikasi (`flutter build apk`, `flutter run`, `.\run.ps1`) sepenuhnya dilakukan oleh pengguna.
- **Verifikasi Error Diperbolehkan**: Pengecekan kode dan verifikasi apakah ada error atau tidak (seperti `flutter analyze` atau compile-check singkat) diperbolehkan untuk memastikan kode bebas dari error/bug sebelum diserahkan ke pengguna.
